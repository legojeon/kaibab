# KaiBab

[English](README.md) · 한국어

식당별 메뉴와 가격을 확인하는 KAIST 식단 확장 프로그램.

[홈페이지](https://legojeon.github.io/kaibab/) · [개인정보처리방침](https://legojeon.github.io/kaibab/privacy.html) · [문의](https://github.com/legojeon/kaibab/issues)

![KaiBab 팝업](store/assets/screenshot-ko-1280x800.png)

## 기능

- 식당 12곳의 메뉴와 운영 정보
- 날짜 및 아침·점심·저녁 선택
- 한국어·영어 지원
- 메뉴 코너 옆 가격 표시
- 마지막 식당·언어 선택 저장
- 연결이 끊겨도 최근 식단 확인, 저장된 메뉴임을 표시

## 설치

Chrome 웹 스토어 등록 전. 아래 순서로 직접 설치.

1. Code → Download ZIP 선택 후 압축 해제
2. Chrome 주소창에 chrome://extensions 입력
3. 개발자 모드 켜기
4. 압축해제된 확장 프로그램을 로드합니다 선택 후 프로젝트 안의 extension 폴더 선택
5. 도구 모음에 KaiBab 고정 후 아이콘 클릭

폴더를 옮긴 경우 새 위치에서 다시 불러오기.

## 개인정보

식당·언어 설정과 최근 식단은 Chrome에 로컬 저장. 광고·분석 도구·개발자 수집 서버 없음.

식단 요청은 KAIST로 직접 전송되며, IP 주소 등 접속 정보가 KAIST에 전달됨. 자세한 내용은 [개인정보처리방침](https://legojeon.github.io/kaibab/privacy.html) 참고.
