# KaiBab

[English](README.md) · 한국어

식당별 메뉴와 가격을 확인하는 KAIST 식단 확장 프로그램.

[홈페이지](https://legojeon.github.io/kaibab/) · [개인정보처리방침](https://legojeon.github.io/kaibab/privacy.html) · [문의](https://github.com/legojeon/kaibab/issues)

## 사용 방법

아이콘을 누르고 식당을 선택하면 메뉴와 가격을 볼 수 있습니다. 날짜와 아침·점심·저녁을 바꿔가며 식단을 확인하세요.

- 식당 12곳의 식단과 운영 정보를 제공합니다.
- KO / EN 버튼으로 한국어와 영어를 전환할 수 있습니다.
- 마지막으로 선택한 식당과 언어는 다음에 열 때도 유지됩니다.
- 인터넷 연결이 끊기면 최근에 불러온 식단을 보여주고, 저장된 메뉴라는 안내를 표시합니다.

## 설치

아직 Chrome 웹 스토어에 등록되지 않아 직접 설치해야 합니다.

1. 저장소 상단의 Code → Download ZIP을 눌러 다운로드한 뒤 압축을 풉니다.
2. Chrome 주소창에 chrome://extensions를 입력합니다.
3. 오른쪽 위의 개발자 모드를 켭니다.
4. ‘압축해제된 확장 프로그램을 로드합니다’를 누르고, 압축을 푼 폴더 안에서 extension 폴더를 선택합니다.
5. 도구 모음에 KaiBab을 고정하면 아이콘을 눌러 바로 사용할 수 있습니다.

설치한 폴더를 옮겼다면 새 위치의 extension 폴더를 다시 불러와 주세요.

## 개인정보

선택한 식당과 언어, 최근에 불러온 식단은 브라우저에만 저장됩니다. 광고나 분석 도구는 사용하지 않으며, 이 정보를 수집하는 별도 서버도 없습니다.

식단을 불러올 때는 KAIST 홈페이지에 직접 접속하므로 IP 주소 등 일반적인 접속 정보가 KAIST에 전달됩니다. 자세한 내용은 [개인정보처리방침](https://legojeon.github.io/kaibab/privacy.html)에서 확인할 수 있습니다.

## 출처

식단 정보는 [KAIST 공식 식단 페이지](https://www.kaist.ac.kr/kr/html/campus/053001.html?dvs_cd=emp)에서 가져옵니다. 메뉴와 운영 시간, 가격은 식당 사정에 따라 달라질 수 있습니다.

KaiBab은 개인이 만든 비공식 확장 프로그램으로, KAIST와 제휴하거나 학교의 승인을 받은 서비스는 아닙니다.
