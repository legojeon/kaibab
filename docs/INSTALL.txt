KaiBab — KAIST 식단
버전 1.2.2 | 개인이 제작한 비공식 크롬 확장 프로그램

설치하기
1. ZIP 파일을 받았다면 먼저 압축을 풀어 주세요.
2. Chrome 주소창에 chrome://extensions 를 입력하세요.
3. 오른쪽 위의 '개발자 모드'를 켜세요.
4. '압축해제된 확장 프로그램을 로드합니다'를 누르세요.
5. 소스 ZIP이라면 extension 폴더를, 스토어 업로드용 ZIP이라면 압축을 푼 폴더를 선택하세요. 선택할 폴더 바로 안에 manifest.json이 있어야 합니다.
6. 크롬 도구 모음의 퍼즐 아이콘에서 'KaiBab — KAIST 식단'을 고정하세요.
7. 밥그릇 아이콘을 누르면 작은 팝업이 열립니다.

별도 빌드, 서버, 계정, API 키가 필요하지 않습니다.
설치 후에도 선택한 폴더를 삭제하거나 옮기지 마세요.
폴더를 옮겼다면 기존 확장 프로그램을 삭제하고 새 위치에서 다시 불러오세요.

사용하기
• 언어: 식당 선택 오른쪽 KO / EN 버튼으로 한국어와 영어를 바꿉니다.
• 언어를 바꾸면 화면 문구와 요청할 KAIST 페이지가 바뀝니다. 원문의 번역 여부나 게시 상태에 따라 식단 내용은 언어별로 다를 수 있습니다.
• 언어를 바꾸는 동안 식당·날짜·시간대는 유지됩니다. 팝업을 다시 열면 식당·언어만 기억하고, 날짜·시간대는 현재 한국 시간을 기준으로 정합니다. 기본 언어는 한국어입니다.
• 영어 식단은 KAIST 공식 영문 페이지에서 직접 불러옵니다. 언어별 캐시는 따로 보관합니다.
• 파란색의 간결한 팝업에서 바로 식당을 선택할 수 있습니다.
• 원문에서 가격을 구분할 수 있으면 메뉴 코너 이름 오른쪽에 표시합니다.
• 식당 선택: 공식 사이트의 식당 항목 12개를 선택할 수 있습니다.
• 아침 / 점심 / 저녁: 처음 열 때 한국 시간을 기준으로 적절한 시간대를 보여줍니다.
• 날짜: 좌우 화살표로 하루씩 이동하거나 날짜를 눌러 달력에서 선택하세요.
• 오늘: 다른 날짜를 보고 있을 때 오늘 날짜로 돌아갑니다.
• 선택 기억: 마지막으로 선택한 식당을 이 브라우저에 저장합니다.
• 새로고침: 오른쪽 위의 둥근 화살표로 원문을 다시 요청합니다. 원문 자체가 최신인지 확인하는 기능은 아닙니다.
• 식당 공지: 원문에 공지가 있으면 메뉴 아래 펼치기 항목에 표시합니다. 운영시간·가격·알레르기 안내의 유무는 원문에 따라 다릅니다.

식당별 표시 방식
날짜별 식단: 카이마루 북측 카페테리아, 서맛골, 동맛골 학생식당,
동맛골 교직원식당, 교수회관, 문지캠퍼스, 화암 기숙사식당, 서울캠퍼스.
메뉴·이용 안내: 카이마루 푸드코트, 패컬티 클럽, 더큰 도시락, 태울관 식당.
공식 페이지가 이용 안내만 제공하는 곳은 원문에서 추출한 안내 문구를 표시합니다. 이미지와 원본 페이지의 배치는 포함하지 않습니다.
빈 식단을 휴무로 단정하지 않습니다. '표시할 식단이 없어요'로 표시합니다.

저장과 연결
5분 이내에 확인한 식단은 저장된 내용을 사용하며, 새로고침하면 다시 요청합니다.
정보를 갱신하지 못하면 유효한 저장본이 있을 때 경고와 함께 표시합니다. 날짜별 식단은 식당·날짜·언어가, 이용 안내는 식당·언어가 일치해야 합니다.
다른 날짜의 식단을 대신 보여주지 않습니다.
캐시는 브라우저의 로컬 저장소에 보관합니다. 7일이 지난 항목과 최근 60개를 초과한 항목은 팝업 실행 또는 저장 시 정리를 시도합니다. 사용하지 않는 동안 즉시 삭제되지는 않습니다. 식단 요청에는 선택한 식당·날짜·언어와 IP 주소 등 일반 접속 정보가 KAIST에 전달됩니다.
최초 실행의 기본 식당은 '교수회관'입니다.

권한
• storage: 선택한 식당·언어와 식단 캐시 저장.
• https://www.kaist.ac.kr/*: 공식 식단 페이지 읽기.
로그인 정보는 요청에 포함하지 않습니다. 분석 도구나 외부 추적 코드를 사용하지 않습니다.
방문 페이지에 코드를 삽입하거나 방문 기록을 읽지 않습니다.
로컬 설치 안내입니다. Chrome 웹 스토어 등록은 별도 절차가 필요합니다.

문제 해결
식단이 안 보이면 새로고침과 인터넷 연결을 확인하세요. 아래 공식 식단 주소에서도 확인할 수 있습니다.
학교 사이트의 구조가 바뀌면 파서 수정이 필요할 수 있습니다.
파일 수정 후에는 chrome://extensions 에서 확장 프로그램의 새로고침 버튼을 누르세요.
기관에서 관리하는 Chrome은 개발자 모드 설치를 제한할 수 있습니다.

개발 참고
manifest.json: Manifest V3 설정과 최소 권한.
popup.html / popup.css / popup.js: 팝업 화면, 상태 관리, 데이터 요청 및 캐시.
data.js: 식당 목록, 한국 시간 기준 날짜 처리, 한영 식단 파서.
locales.js: 한국어·영어 화면 문구와 짧은 식당 이름.
icons/: 직접 제작한 밥그릇 아이콘. KAIST의 공식 로고가 아닙니다.
라이브러리나 빌드 도구 없이 바로 수정할 수 있습니다.

English quick start
Extract the ZIP, open chrome://extensions, enable Developer mode, and click Load unpacked.
For the source ZIP, choose its extension subfolder. For the store upload ZIP, choose the extracted folder itself. The chosen folder must directly contain manifest.json. Then pin the extension.
Click EN next to the cafeteria selector to use English. Your language choice is remembered.
Menus are loaded directly from KAIST’s English website; missing menus are shown as unavailable.
To update an existing installation, replace its files and click Reload in chrome://extensions.
