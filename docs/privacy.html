KaiBab Privacy Policy

개인정보처리방침 · Last updated / 최종 수정: 2026-10-29 · Extension versions 1.2.0–1.2.2

English한국어KaiBab

What KaiBab does

KaiBab is an unofficial browser extension maintained by legojeon. It displays public KAIST cafeteria menus and dining information in Korean and English. It is not affiliated with, endorsed by, or operated by KAIST.

Information processed on your device

The extension stores your selected cafeteria and language in Chrome’s local extension storage. It also caches public menu text, prices, dining hours, notices, the requested cafeteria/date/language, and the time the menu was fetched. This is used to display menus and remember your cafeteria and language. A saved copy may be displayed without a new request for five minutes. If an update attempt fails, an existing valid saved copy remains visible with a warning. Saved daily menus must match the selected cafeteria, date and language; dining guides match cafeteria and language.

KaiBab does not read your browsing history, other tabs, personal files, contacts, passwords, authentication cookies, payment information or precise location. It contains no advertising, analytics, usage tracking or developer-operated collection server. It does not use Chrome storage sync.

Requests to KAIST

When you open the popup or change the selected cafeteria, date or language, it may request the corresponding public page at https://www.kaist.ac.kr. Refresh requests a new copy. The request includes the cafeteria identifier, selected date (for daily menus) and language in the URL. KAIST necessarily receives normal connection information such as your IP address and browser/network headers and may retain its own server logs. KaiBab does not control KAIST’s logging or privacy practices.

Requests use HTTPS, omit cookies and other fetch credentials, send no referring-page URL, and do not follow redirects. Menu requests are initiated from the popup. The extension has no background menu polling. Cached menus may avoid a new request for five minutes. Downloaded HTML is read as data; remote JavaScript is not executed.

Retention and deletion

Preferences remain locally until you change them or remove the extension. Cached menus older than seven days and entries beyond the latest 60 are cleaned up when the popup opens or new menus are stored; cleanup is best effort. If you do not reopen the extension, expired cache files may remain on disk but are not displayed as valid cache. Removing KaiBab from chrome://extensions deletes its local extension storage. Clearing ordinary browsing history alone does not necessarily remove extension storage.

Sharing and use

KaiBab does not sell user data, use it for advertising, or use it for creditworthiness or lending decisions. It uses preferences and public menu content only for its cafeteria-menu feature. There is no developer backend receiving menu selections or cached data.

Support and this policy website

Contact the maintainer through KaiBab GitHub Issues. Issues are public; do not include passwords, student identifiers or other sensitive information. If you voluntarily submit an issue, your GitHub username and submitted content are handled on GitHub and are visible to the maintainer and others. This policy website is hosted on GitHub Pages; GitHub may process ordinary site access information under its own privacy statement. Opening a support or policy link is separate from using the extension.

Changes

This page will be updated if KaiBab’s data practices change. Material new data use will be disclosed before it is introduced.

KaiBab의 목적과 운영자

KaiBab은 legojeon이 관리하는 비공식 브라우저 확장 프로그램으로, 공개된 KAIST 식단과 식당 이용 안내를 한국어·영어로 보여줍니다. KAIST가 제작·운영·보증하는 서비스가 아닙니다.

기기에서 처리하는 정보

선택한 식당과 언어를 Chrome의 확장 프로그램 로컬 저장소에 저장합니다. 공개 식단의 메뉴명·가격·운영시간·공지, 요청한 식당·날짜·언어, 불러온 시각도 캐시에 저장합니다. 식단 표시와 식당·언어 선택 기억에 사용합니다. 불러온 지 5분 이내에는 새 요청 없이 저장된 내용을 보여줄 수 있습니다. 갱신을 시도하다 실패하면 유효한 저장본이 있을 때 경고와 함께 표시합니다. 날짜별 식단은 선택한 식당·날짜·언어, 이용 안내는 식당·언어가 일치하는 저장본만 사용합니다.

방문 기록, 다른 탭, 개인 파일, 연락처, 비밀번호, 인증 쿠키, 결제 정보, 정밀 위치를 읽지 않습니다. 광고·분석·사용 추적 코드 및 개발자가 운영하는 수집 서버가 없습니다. Chrome 동기화 저장소를 사용하지 않습니다.

KAIST로 보내는 요청

팝업을 열거나 식당·날짜·언어를 바꾸면 https://www.kaist.ac.kr의 해당 공개 페이지를 요청할 수 있습니다. 새로고침하면 새로 요청합니다. 요청 URL에는 식당 코드, 날짜별 식단의 선택 날짜, 언어가 포함됩니다. 접속 과정에서 KAIST에는 IP 주소와 브라우저·네트워크 헤더 등 일반적인 연결 정보가 전달되며, KAIST가 자체 접속 기록을 보관할 수 있습니다. KaiBab은 KAIST의 기록 보관 및 개인정보 처리 방식을 통제하지 않습니다.

HTTPS를 사용하며 쿠키 등 fetch 인증 정보를 포함하지 않고, 참조 페이지 URL을 보내지 않으며, 리다이렉트를 따라가지 않습니다. 메뉴 요청은 팝업에서 시작하며, 백그라운드에서 주기적으로 식단을 수집하지 않습니다. 5분 이내 캐시는 새 요청 없이 표시할 수 있습니다. 원격 HTML은 데이터로 읽으며 원격 JavaScript는 실행하지 않습니다.

보관과 삭제

선택 설정은 변경하거나 확장 프로그램을 삭제할 때까지 기기에 남습니다. 7일이 지난 캐시와 최근 60개를 초과한 항목은 팝업 실행 또는 새 식단 저장 시 정리를 시도합니다. 팝업을 다시 열지 않으면 만료된 데이터가 디스크에 남을 수 있으나 유효한 캐시로 표시하지 않습니다. chrome://extensions에서 KaiBab을 삭제하면 확장 프로그램의 로컬 저장 데이터가 삭제됩니다. 일반 방문 기록 삭제만으로 확장 프로그램 저장 데이터가 지워지는 것은 아닙니다.

공유와 이용

정보를 판매하거나 광고·신용도·대출 판단에 사용하지 않습니다. 선택 설정과 공개 식단은 식단 확인 기능에만 사용합니다. 식당 선택이나 캐시를 받는 개발자 서버가 없습니다.

문의와 방침 웹사이트

KaiBab GitHub Issues로 문의할 수 있습니다. Issues는 공개되므로 비밀번호·학번 등 민감한 내용을 올리지 마세요. 직접 제보한 경우 GitHub 사용자명과 작성 내용은 GitHub에서 처리되며 운영자와 다른 방문자가 볼 수 있습니다. 이 방침은 GitHub Pages에 게시되어 있으며, 사이트 접속 시 GitHub의 개인정보처리방침에 따라 접속 정보가 처리될 수 있습니다. 지원·방침 링크 방문은 확장 프로그램 사용과 별개입니다.
