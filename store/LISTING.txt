ENGLISH DESCRIPTION
View menus and prices from the KAIST website in a compact Chrome popup.

Choose from the 12 cafeteria options listed on the website. Eight options show daily menus for published dates; the other four show menus and dining guides without a date selector. Prices are shown where the source provides them.

• Select breakfast, lunch or dinner for daily menus.
• Switch between the Korean and English KAIST pages. Content can differ between the two pages.
• Keep your last cafeteria and language selection. Dates and meals reset to the current Korean date and time when the popup opens.
• Reuse a matching previously loaded menu while a valid saved copy remains. Saved information may be out of date.

Privacy: The extension saves preferences and public menu content in local Chrome storage. Menu requests go directly to KAIST with the selected cafeteria/date/language and ordinary connection information such as your IP address. No ads, analytics, extension login or developer-operated collection server.

KaiBab is independently developed and is not affiliated with, endorsed by or operated by KAIST. The menu source is the KAIST website; the extension extracts its text for display and does not reproduce the entire page. Menus, hours and prices may change. A missing menu does not mean a cafeteria is closed.

SINGLE PURPOSE
Display public KAIST cafeteria menu text and dining information in a compact popup. Users select a cafeteria and source language, and a date and meal where daily menus are available.

PERMISSION JUSTIFICATION — storage
Store the selected cafeteria and language, plus a bounded local cache of public menu data. No Chrome storage sync or developer backend is used. A saved copy can be reused without a request for five minutes; this is not a guarantee that the source is current. Older copies are used while requesting an update or as a fallback after an update fails. Invalid or expired copies are not used. Cleanup of entries older than seven days or beyond the latest 60 is attempted on popup launch and cache writes.

HOST PERMISSION JUSTIFICATION — https://www.kaist.ac.kr/*
Fetch the official public Korean and English cafeteria HTML pages selected in the popup. Code and CSP restrict requests to /kr/html/campus/053001.html and /en/html/campus/053001.html. Chrome host permissions are granted at host/scheme scope, so narrowing a manifest path would not reduce the actual host permission. No content scripts or other-site access.

REMOTE CODE
No, I am not using remote code.
All JavaScript is packaged with the extension. Retrieved HTML is parsed as text data by local code; its scripts and event handlers are not executed.

REVIEWER NOTES
No account or login is needed. Open the toolbar popup, choose Faculty · N6 / 교수회관 · N6, and choose Lunch / 점심. KO and EN switch both source page and UI. Some dates or meals are empty or unavailable; use a weekday with a posted menu. Prices and notices depend on the source. Date/meal controls are available only for daily-menu options. Food Court / Faculty Club / Durken Dosirak / Taeulgwan show dining guides. Settings are local. The school website is a public external dependency and may be temporarily unavailable.
