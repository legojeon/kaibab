KaiBab · 보안 및 출시 준비 검토

검토일: 2026-10-29 · 대상 버전: 1.2.0 · 검토 범위: 패키지 소스, 권한, 네트워크·저장·렌더링, 실제 브라우저 동작, 웹 스토어 제출 자료

현재 코드에서 중대한 취약점은 발견하지 못했습니다. 권한과 데이터 흐름을 검토하고 방어 코드를 보강했습니다. 제출 자료, 공개 GitHub 저장소와 GitHub Pages 게시를 완료했습니다. 홈페이지·개인정보처리방침·문의 링크가 로그인 없이 HTTP 200으로 열리는 것을 확인했습니다. 웹 스토어 계정 설정·최종 제출은 아직 완료되지 않았습니다. 이 검토가 Google의 승인이나 모든 취약점 부재를 보장하지는 않습니다.

1.2.1 변경: 한영 패키지 요약과 버전 표기만 수정. 실행 로직·권한·데이터 처리 방식은 1.2.0과 동일하며, 아래 브라우저 테스트 결과는 1.2.0 기준입니다. 1.2.1에서는 패키지 메타데이터와 ZIP 내용을 확인했습니다.

발견한 문제와 처리

우선순위발견 사항처리
출시 필수기존 ZIP은 최상위 폴더 안에 manifest.json이 있어 스토어 업로드 형식과 달랐음.명시적 파일 목록으로 스토어용 ZIP을 별도 생성. manifest.json이 최상위이며 테스트·문서·개인 파일은 제외.
출시 필수공개 개인정보처리방침과 지원 주소가 없었음. “개발자 서버 없음”만으로 로컬 처리 고지를 생략할 수 없음.한영 개인정보처리방침과 GitHub Pages용 파일 준비. 설정/캐시/KAIST 요청/IP 접속 정보/삭제/지원 경로 명시. 공개 URL 접속 검증 완료.
출시 필수380×520 팝업 캡처는 제출 스크린샷 규격이 아님. 128px 아이콘에 권장 여백 부족.실제 UI로 1280×800 한영 이미지 제작. 128px 아이콘은 96px 그림 + 16px 투명 여백. 선택용 440×280 홍보 이미지 포함.
보안 보강fetch는 기본 리다이렉트를 따르고 응답 크기·형식의 별도 제한이 없었음.정확한 HTTPS 출처/두 식단 경로만 허용. redirect:error, text/html 확인, Content-Length 및 스트림 누적 2MiB 제한. 12초 제한 유지.
안정성 보강손상된 캐시의 내부 값 검증이 약했고 60개 정리가 팝업 시작 시에만 수행됨.캐시 타입·항목·텍스트 길이·시각 검증. 새 캐시 기록 뒤에도 정리. 만료 데이터는 유효 캐시로 사용하지 않음.
방어 강화CSP에 포괄적인 기본 차단 규칙이 없었음.default-src 'none', 로컬 스크립트/스타일, 정확한 두 connect-src 경로, 폼·프레임·객체 제한. 저장소는 TRUSTED_CONTEXTS로 제한.
표기브랜드와 비공식 관계를 스토어 설명에서 명확히 할 필요.KaiBab 표기와 한영 manifest 메타데이터 적용. 독자 제작 밥그릇 아이콘 유지, KAIST 공식 로고 없음. 제휴·보증받지 않았다는 문구 포함.

데이터와 권한

항목실제 동작
storage식당·언어 선택 및 공개 식단 캐시만 Chrome 로컬 저장소에 저장. 동기화·개발자 서버 없음.
https://www.kaist.ac.kr/*호스트 권한은 Chrome 특성상 출처 범위. 코드와 CSP는 /kr/html/campus/053001.html 및 /en/html/campus/053001.html에 제한.
네트워크팝업 사용 중에만 공개 식단을 직접 조회. HTTPS, 인증 쿠키 제외, referrer 제외. KAIST는 IP·일반 HTTP 헤더와 식당/날짜/언어 요청을 받을 수 있음.
원격 코드없음. 다운로드한 HTML에서 텍스트만 추출하고 textContent로 새 UI 노드에 표시. 외부 스크립트·이벤트 속성·HTML을 화면에 삽입하지 않음.
미사용 권한tabs, history, cookies, scripting, activeTab, <all_urls>, 외부 메시징, content scripts, background worker 없음.
보관설정은 변경/확장 삭제까지. 캐시는 5분 신선도, 7일 및 최신 60개 기준으로 시작/기록 시 정리 시도. 미실행 기간의 즉시 삭제를 보장하지 않음.

검증 결과

  • 실제 Chromium 확장으로 한국어 12곳 + 영어 12곳의 공식 페이지 조회 통과.
  • 언어 저장, 날짜 이동, 빠른 언어 전환, 가로 넘침, 미처리 오류 확인 통과.
  • 공격용 script, onerror, iframe 및 HTML 문자열이 실행되거나 실제 UI 노드가 되지 않음.
  • 외부 이미지·프레임 URL로 요청이 발생하지 않음.
  • 허용되지 않은 목적지, 잘못된 MIME, 큰 Content-Length, 길이 헤더 없는 2MiB 초과 응답 차단.
  • 실제 302 응답을 따라가지 않으며 저장 메뉴 경고로 처리.
  • 손상된 캐시 거부, 최대 60개 정리 및 언어별 분리 검증.
  • 배포 파일 목록, ZIP 최상위 manifest, 구문과 SHA-256 확인.

아직 남은 공개·제출 단계

  1. legojeon/kaibab 공개 저장소 생성·게시 완료.
  2. main 브랜치의 docs 폴더로 GitHub Pages 게시 완료. 개인정보처리방침·홈페이지·문의 링크 공개 접속 확인.
  3. 웹 스토어 개발자명·이메일 인증·등록 절차 완료. GitHub 지원 주소가 이메일 인증을 대체하지 않음.
  4. 스토어의 실제 개인정보 필드 확인. 공개 메뉴를 Website content로 고지하고 로컬 설정 처리와 KAIST 직접 요청을 설명.
  5. KAIST 공개 콘텐츠의 재이용 조건 확인. 이 검토는 콘텐츠 이용 허락이나 상표 승인을 확정하지 않음. 공개 소스의 라이선스는 아직 선택하지 않음.
  6. 업로드 파일·스크린샷·권한 사유·국가/공개 설정을 확인하고 Google 심사에 제출.

이름 제안

KaiBab 권장: Kai와 Bab(밥)이 눈에 구분됩니다. 저장소·폴더는 kaibab, 스토어는 KaiBab — KAIST Menu / KaiBab — KAIST 식단이 적절합니다. KAIBAB은 전체가 약어처럼 보이고, Kaibab은 두 단어의 구분이 덜 선명합니다. 이 추천은 가독성 판단이며 상표 등록 가능성을 조사한 결과는 아닙니다.
