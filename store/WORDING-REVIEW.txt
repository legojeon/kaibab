KaiBab 문구 검토 — 2026-10-29 / 1.2.2

범위
한영 패키지 요약과 제목, 팝업·접근성 안내, 식당 이름, README 두 언어,
설치 안내, 홈페이지, 개인정보처리방침 두 언어, 스토어 소개·심사자 안내,
권한·데이터 고지, 체크리스트·검토 보고서, 스크린샷·홍보 이미지 문구.

수정 사항
1. 출처와 제작 주체
   공식이라는 표현은 KAIST 홈페이지에만 사용. 패키지 요약은 1.2.1에서
   확정한 문구 유지. 상세 설명에서 KaiBab의 독립 제작·비제휴 관계 명시.
   홈페이지의 모호한 Unofficial 단독 표현을 제작 주체에 관한 문장으로 변경.
2. 식당 12곳과 날짜 선택
   사이트의 12개 선택 항목임을 명시. 날짜별 식단 8개, 메뉴·이용 안내 4개를
   구분하고, 원문에 게시된 날짜만 확인할 수 있음을 스토어 설명에 반영.
3. 가격·이용 안내
   모든 메뉴에 가격이 있다는 인상을 주지 않도록 원문에 기재된 경우로 한정.
   고정 메뉴라는 표현은 메뉴·이용 안내로 변경. 안내문은 원문 전체 복제가 아닌
   추출 텍스트임을 명시. 팝업의 공지 제목은 식당 공지로 변경.
4. 연결 실패·저장된 식단
   유효한 저장본이 남아 있고 선택 항목과 일치해야 사용 가능.
   5분 이내 재사용은 최신성 보장이나 항상 표시되는 캐시 경고를 뜻하지 않음.
   갱신 실패 안내는 네트워크 장애만을 원인으로 단정하지 않도록 수정.
5. 선택 기억
   저장하는 설정은 식당과 언어. 날짜와 식사 시간은 팝업을 다시 열면
   현재 한국 시간을 기준으로 정한다는 내용을 명확히 함.
6. 한국어·영어
   자체 번역이나 두 원문의 완전한 일치를 보장하지 않음.
   해당 언어의 KAIST 페이지를 요청하며 원문 내용은 다를 수 있음을 설명.
   영어 동측 학생식당 표기는 원문 East-Campus Graduate에 맞춰 East · Graduate로 수정.
7. 데이터 처리
   로컬에 보관하는 설정·캐시와 KAIST로 보내는 식당·날짜·언어/IP 접속 정보를
   구분. 네트워크 전송이 전혀 없다는 인상을 주는 해석을 방지.
   백그라운드 정기 조회가 없다는 사실과, 닫힌 팝업의 네트워크 상태를
   단정하는 표현을 구분. 캐시 정리는 실행/저장 시의 최선 노력임을 유지.
8. 오류 안내
   미등록/형식 변경 등 확인하지 못한 원인을 단정하지 않고,
   식단을 찾지 못함/표를 읽지 못함/시간 정보 없음으로 변경.
9. 설치·제출 안내
   소스 ZIP과 스토어 ZIP의 선택 폴더 차이를 설명.
   게시 여부·계정 절차 완료를 확인 없이 단정하는 문구 제거.
   오픈소스 라이선스 선택을 스토어 제출 필수 항목에서 분리.
